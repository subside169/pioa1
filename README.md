# In-memory база данных книг

## Описание проекта

Проект представляет собой прототип базы данных, работающей в оперативной памяти.

В качестве предметной области выбрана таблица книг. Программа позволяет:
- добавлять записи;
- получать записи с фильтрацией по одному или нескольким полям;
- обновлять записи;
- удалять записи;
- работать через консольный интерфейс.

Реализация выполнена на языке Python с применением объектно-ориентированного подхода и автоматизированного тестирования.

## Функциональность

Реализовано:
- хранение данных в памяти;
- создание записей о книгах;
- выборка записей с фильтрацией;
- обновление записей;
- удаление записей;
- обработка ошибок с помощью пользовательских исключений;
- консольный интерфейс для работы с базой данных;
- автоматизированные тесты для основного функционала.

Дополнительно реализовано:
- переписанный на класс консольный интерфейс.
