# In-Memory база данных книг (ООП-версия)

## Описание проекта
Прототип базы данных, работающей в оперативной памяти. Версия 2: объектно-ориентированная реализация с автоматическими тестами.

Реализована работа с таблицей **книги** (book_id, title, author, year, genre).
Поддерживаются операции добавления, просмотра, поиска по фильтрам, обновления и удаления записей.

Пользовательский интерфейс представлен классом `BookTUI` (консольное меню).
Код покрыт модульными тестами (`unittest` + `pytest`) с использованием `mock`-объектов. Общее покрытие строк кода – 99%.

## Функциональность
- **Добавление книги**: проверка уникальности ID, корректности года.
- **Просмотр всех книг**: вывод полного списка.
- **Поиск по фильтрам**: комбинация любых полей (id, title, author, year, genre).
- **Обновление записи**: изменение выбранных полей, проверка корректности новых данных.
- **Удаление записи**: по ID, с проверкой существования.
- **Обработка ошибок**: через собственные исключения (`DuplicateIDError`, `InvalidYearError`, `RecordNotFoundError`).

## Тестирование

Проект покрыт автоматическими модульными тестами с использованием фреймворка `unittest` и запускается через `pytest`.  
Для эмуляции пользовательского ввода в тестах интерфейса применяются `Mock`-объекты.  

Общее покрытие строк кода – **99%**.

### Запуск тестов
```bash
python -m pytest
pip install pytest-cov
pytest --cov=src --cov-report=term-missing
```
