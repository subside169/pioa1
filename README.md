# In-Memory база данных книг

## Описание проекта
Данный проект представляет собой прототип базы данных, работающей в оперативной памяти (in-memory).

Реализована работа с одной таблицей — **книги**.  
Программа позволяет добавлять записи, обновлять, удалять, просматривать их и выполнять поиск с использованием фильтров.

Проект реализован на языке Python с использованием консольного интерфейса.

## Функциональность

- Добавление записи о книге
- Просмотр всех записей
- Поиск записей по фильтрам:
  - id
  - title (название)
  - author (автор)
  - year (год)
  - genre (жанр)
- Обновление записей
- Удаление записей
- Обработка ошибок:
  - ввод некорректных данных
  - попытка добавить запись с существующим id
  - проверка корректности числовых значений
