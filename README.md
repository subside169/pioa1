# In-Memory и файловая база данных книг

## Описание проекта
Прототип системы управления данными с поддержкой нескольких способов хранения: в оперативной памяти (in-memory) и в файлах (JSON, CSV). Реализован единый интерфейс доступа к данным через абстрактный класс `Database`.

Программа позволяет работать с таблицей **книги** (book_id, title, author, year, genre). Поддерживаются создание таблицы, добавление, поиск с фильтрацией, обновление и удаление записей. Пользовательский интерфейс реализован в виде консольного меню (класс `BookTUI`).

Код покрыт автоматическими тестами (`unittest` + `pytest`). Общее покрытие строк кода – 90%.

## Функциональность
- **Выбор типа хранилища** при запуске (in-memory, JSON, CSV).
- **Создание таблицы** с заданными колонками.
- **Добавление записи** с валидацией на соответствие схеме.
- **Просмотр всех записей** таблицы.
- **Поиск записей** по одному или нескольким полям.
- **Обновление записи** по идентификатору (первая колонка).
- **Удаление записи** по идентификатору.
- **Сохранение данных на диск** и их загрузка при следующем запуске (для файловых БД).
- Обработка ошибок через собственные исключения.

## Различия реализаций баз данных

| Характеристика             | MemoryDatabase      | FileDatabase (JSON)        | CsvDatabase (CSV)         |
|----------------------------|---------------------|----------------------------|---------------------------|
| Хранение                   | В оперативной памяти| В JSON-файлах (data/*.json)| В CSV-файлах (data/*.csv) |
| Сохранение между запусками | Нет             | Да                         | Да                        |
| Читаемость                 | –                   | Да                         | Да (табличный вид)        |
| Простота реализации        | Максимальная        | Средняя (работа с JSON)    | Средняя (работа с CSV)    |
